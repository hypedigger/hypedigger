# Hey, I'm HypeDigger 👋

I build **free, open-source tools** that scratch real itches — AI-powered image pipelines, media utilities, and offline Android apps. No ads, no tracking, no paywalls. Ever.

## 🎨 AI & images

| | |
|---|---|
| **[PortraitForge](https://github.com/hypedigger/PortraitForge)** | Re-style a whole game's character portraits with Stable Diffusion (ComfyUI + ControlNet) and ship them as an HD texture pack. Generation queue, curation UI, pack export. |
| **[ComicRestyler](https://github.com/hypedigger/ComicRestyler)** | Redraw manga/comic/BD pages in another art style — speech bubbles detected and preserved. |
| **[LrAutoKeyword](https://github.com/hypedigger/LrAutoKeyword)** | Lightroom Classic plugin: AI keywording with Claude that only uses *your* catalog's keywords, with review before apply. |

## 🖼️ Media utilities (Windows)

| | |
|---|---|
| **[SpeedDisplay](https://github.com/hypedigger/SpeedDisplay)** | Very fast image & video viewer — Rust (Tauri 2), virtualized grid, RAW previews, lossless video remux. |
| **[DCIM-Sorter](https://github.com/hypedigger/DCIM-Sorter)** | Import photos from SD cards & MTP phones into a clean year/month/day tree from EXIF dates. |
| **[AudioBatch-Converter](https://github.com/hypedigger/AudioBatch-Converter)** | Batch-convert a music library (FLAC/WAV/APE → MP3/OGG/Opus) with tags & covers preserved, MusicBrainz auto-tagging. |
| **[BookScan-Extractor](https://github.com/hypedigger/BookScan-Extractor)** | Extract page images from scanned book PDFs and re-join double-page spreads — lossless, with a smart pairing score. |
| **[BookBinder](https://github.com/hypedigger/BookBinder)** | Merge two scanned comic pages into a double-page spread with one hotkey, straight from Explorer. |
| **[PadBoard](https://github.com/hypedigger/PadBoard)** | Turn any gamepad into a soundboard — a sound on every button, trigger and stick. |
